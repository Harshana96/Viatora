# Skill: Knowledge Base Maintenance

Use when a change affects architecture, domain rules, or feature behavior.

1. Identify the correct file under `knowledge/` (product, architecture,
   domain, features, decisions, operations) — do not create a new top-level
   knowledge document without good reason.
2. Update the relevant section rather than appending unrelated notes.
3. For significant architectural decisions, add a new ADR under
   `knowledge/decisions/`.
