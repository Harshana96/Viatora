# Skill: Admin CRUD

Use when building admin management screens (destinations, places, packages,
enquiries).

1. Read `knowledge/features/` doc relevant to the entity.
2. Reuse shared form patterns (React Hook Form + Zod) already established
   in `src/components/admin/`.
3. Require authentication on every admin route and server action.
4. Update `knowledge/` docs if the admin workflow changes materially.
