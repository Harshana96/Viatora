# UI/UX Rules

- Mobile-first: design and test mobile layout before tablet/desktop.
- Package page order: Hero -> Summary -> Journey map -> Day-by-day itinerary
  -> Places -> Gallery -> Included/excluded -> Enquiry CTA.
- Desktop: itinerary and map side-by-side. Mobile: map above itinerary.
- Clicking a day in the itinerary focuses the map on that day's location;
  clicking a map marker highlights the corresponding itinerary item.
- Use shadcn/ui components where practical instead of building bespoke
  primitives.
