# User Flows

## Visitor discovers and enquires about a tour
1. Land on Home -> browse popular packages/destinations.
2. Open Tour Packages -> filter by duration/destination/type/budget.
3. Open a package detail page -> review itinerary + journey map.
4. Click a day in the itinerary -> map focuses that day's location (and
   vice versa when clicking a marker).
5. Submit an enquiry from the package page.

## Admin manages content
1. Log in to the admin panel.
2. Create/edit destinations and places (with coordinates).
3. Create a tour package, then build its itinerary day by day, assigning
   places to each day.
4. Review dashboard totals and manage incoming enquiries (status +
   internal notes).
