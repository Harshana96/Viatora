# MVP Scope

See `sri-lanka-tourism-mvp-claude-code-spec.md` at the repo root for the full
specification. Summary:

## Public site
Home, tour package listing (search/filter), package detail (with journey
map + itinerary), destination pages, enquiry form.

## Admin panel
Dashboard, package/destination/place CRUD, itinerary builder, enquiry
management.

## Out of scope for MVP
User accounts, reviews, tour operators, wishlists, online booking/payments,
AI itinerary planner, multi-language, mobile app. See spec section 18.
