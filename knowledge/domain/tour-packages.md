# Tour Packages

A `TourPackage` has a cover image, name, duration, price (or starting
price), an optional `travelType` (see `knowledge/features/tour-search-filters.md`),
short description, highlights, an ordered list of `TourDay`s,
included/excluded items, a gallery, and an enquiry CTA. Packages can be
published/unpublished and archived by an admin.
